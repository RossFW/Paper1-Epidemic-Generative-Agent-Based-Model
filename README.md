# Paper 1: Epidemic Generative Agent-based Model

Dissertation chapter / Paper 1 of the three-paper dissertation *Epidemic
Modeling with Generative Agents* by Ross Williams (Virginia Tech).

A generative agent-based epidemic model in which LLM-driven agents (GPT-3.5)
make daily stay-home / go-out decisions in an SIR-style outbreak, under
different information-feedback conditions. This is the author's full working
estate for the paper — code, raw and processed simulation data, analysis, and
manuscript.

> **Published version & original code:** the peer-reviewed paper is
> *"Epidemic modeling with generative agents"* (arXiv:2307.04986). The original
> published codebase lives at **[bear96/GABM-Epidemic](https://github.com/bear96/GABM-Epidemic)**
> (co-author's account). **This repository** is the author's dissertation
> reproduction plus the complete data and analysis behind the chapter.

## Repository layout

```
Code/GABM Updated/   Simulation engine + analysis scripts
  ├── main.py, world.py, agent.py, citizen.py   Mesa model + LLM agent loop
  ├── mobility.py, datacollector.py, utils.py   Mobility logic + data capture
  ├── eval.py, evaluation.py, extract_pkl.py    Evaluation + data extraction
  ├── logistic.py, *.Rmd, *.ipynb               Logistic-regression analysis
  └── *.csv                                      Per-run + pooled outputs
Data Raw/            Raw simulation output by feedback condition
  ├── Full Feedback/ Health Feedback/ No Feedback/
  └── Logistic Regression Data from R03/
Analysis/            Collective + individual analysis workbooks and figures
Writing/             Manuscript (Version 2/Ross_GABM_Paper_v7_finished.docx)
```

## Data notes

- **Pickled checkpoints (`*.pkl`) are not committed** (~859 MB of regenerable,
  non-portable simulation state). The usable data is provided as CSV exports in
  `Code/GABM Updated/` and `Data Raw/`. The pickles can be regenerated by
  re-running the simulations, or are available on request.
- **`Analysis/Individual Analysis/Individual Analysis.xlsx`** (101 MB) is stored
  via **Git LFS**. Install Git LFS (`git lfs install`) before cloning to pull it.
