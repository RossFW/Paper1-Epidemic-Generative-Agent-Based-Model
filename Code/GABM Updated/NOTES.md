# Regression outputs — which file is canonical

**`final_model_coefficients.csv` is the reported regression result.**
`model_coefficients.csv` holds the same values at full precision; `final_model_*`
is the rounded, presentation-formatted version.

Verified against the published Table 1 (also Chapter 2 of the dissertation):
the coefficients and fit statistics match exactly —

| Reported (Table 1) | `final_model` |
|---|---|
| Societal Health (Reg 2) = 0.26 | CaseFeedback FE2 = 0.2643 |
| Societal Health (Reg 3) = 0.52 | CaseFeedback FE3 = 0.5248 |
| Societal Health² = −0.02 | CaseFeedback² = −0.0176 |
| Age (Reg 4) = 0.08 | age RE4 = 0.0801 |
| BIC 42071 / 36804 / 36028 / 31062 | identical |
| Pseudo-R² 0.337 / 0.441 / 0.456 | identical |

## The models

Four columns, fit on `Run1_Indiv_Data_for_logistic_regression.csv`:

- **FE1–FE3** — fixed-effects logits of increasing specification (cough severity →
  + societal-health feedback and its square → full controls).
- **RE4** — random-effects logit adding the Big Five traits, age, and gender.

Generated by **`logistic_regression_v2.Rmd`**.

## Removed (June 2026)

Earlier scripts `v3`–`v6_logistic_regression.Rmd` and their `*_model_coefficients.csv` /
`*_model_gof_stats.csv` were **predictor-scaling experiments** — the same models with
the continuous predictors centered (`v3`: `CF_c`, `age_c`) or z-scored
(`v6`: `CF1`, `age_z`). They were not the reported specification and were removed to
avoid ambiguity. They remain in git history if ever needed.
